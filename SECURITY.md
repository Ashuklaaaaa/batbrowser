# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

Security is a core priority for BatBrowser.

If you discover a vulnerability or security flaw:
1. Please **do not** open a public GitHub issue.
2. Send a detailed report to `security@batbrowser.com` or via security advisory.
3. Include steps to reproduce, affected versions, and potential impact.

We respond to all security reports within 24 hours.
