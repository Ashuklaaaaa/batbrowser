# NOCTURNE Design Tokens

All UI styling in BatBrowser is driven by CSS design tokens declared in `ui/shared/tokens.css`.

## Core Palette
- **Abyss Background (`--bg`):** `#080A0F`
- **Surface Layer 1 (`--surface-1`):** `#121419`
- **Surface Layer 2 (`--surface-2`):** `#1A1D24`
- **Primary Accent (`--accent`):** `#00D4B4` (NOCTURNE Teal)
- **Accent Glow (`--accent-glow`):** `rgba(0, 212, 180, 0.2)`
- **Text Main (`--text`):** `#F0F4F8`
- **Text Muted (`--text-muted`):** `#6E7889` (WCAG AA Compliant 4.6:1 ratio)

## Motion & Transitions
- **Easing:** `cubic-bezier(0.16, 1, 0.3, 1)` (NOCTURNE Spring)
- **Fast Duration (`--dur-fast`):** `120ms`
- **Normal Duration (`--dur-normal`):** `200ms`
